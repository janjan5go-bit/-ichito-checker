◎ / ○ / △ / × の判定ルール
これは市場全体の絶対基準ではなく、このツールで採用している購入判断ルール。目標利回り・返済比率・経費率は下の設定から変更可能。
20%家賃消失時CF：◎ 満室年収の5%以上残る / ○ 0円以上 / △ 0〜▲5% / × ▲5%超
表面利回り：◎ 目標＋2pt以上 / ○ 目標以上 / △ 目標−1pt以上 / × それ未満
返済比率：◎ 目安の80%以下（50%設定なら40%以下）/ ○ 目安以下 / △ 目安の110%以下 / × それ超
経費率：◎ 目安より約5pt以上低い（30%設定なら25%以下）/ ○ 目安以下 / △ 目安の110%以下 / × それ超
DSCR：◎ 1.50以上 / ○ 1.30以上 / △ 1.10以上 / × 1.10未満
損益分岐稼働率：◎ 75%以下 / ○ 80%以下 / △ 85%以下 / × 85%超
